## 📖 网站介绍

马列毛主义学习站，是一个以宣传马克思、恩格斯、列宁、斯大林、毛泽东的革命思想为宗旨的公益学习网站。本站致力于：

* 整理革命导师的经典著作，提供书籍免费下载；
* 汇集马列毛主义理论文章；
* 收集视频、图片等各类学习资源，供所有愿意学习的人自由使用。

我们尤其希望服务那些刚刚接触共产主义的读者。你不需要任何理论基础：从基本概念开始，一步一步读懂经典、理解历史、认识现实。理论不是少数人的装饰，而是劳动者认识世界、改造世界的武器。本站愿与一切追求进步的人一起，为全人类的解放而斗争。

无论你此前是否了解共产主义，都可以从这里开始，逐步读懂、学会、用得上。
